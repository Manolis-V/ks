# ⏳ Countdown Timer  

A simple yet dynamic **countdown website** that continuously updates in real-time, showing:  
✅ **Days Passed**  
✅ **Days Left**  
✅ **Percentage Progress** (with high precision, changing every second)  

🚀 Live Demo: [KS](https://manolis-v.github.io/ks)

---

## 🎨 Features  

- **Real-Time Updates**: The percentage progress updates every second with multiple decimal places.  
- **Dark & Light Themes**: Switch between themes using a button. Your preference is saved in the session.  
- **Responsive Design**: Works smoothly across different devices.  
- **GitHub Pages Deployment**: Hosted directly on GitHub for easy access.  

---

## 🛠️ Tech Stack  

- **HTML, CSS, JavaScript**  
- **Session Storage** (to remember theme preferences)  
- **GitHub Pages** (for hosting)  

---

## 🚀 Setup & Usage  

1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/countdown.git
   cd countdown
   ```
2. Open ```index.html``` in a browser.
3. Enjoy the real-time countdown! 🎉
